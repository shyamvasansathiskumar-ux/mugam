How Mugam keeps your face private
  1. Your face stays here. The camera picture is read in memory on this device and thrown away. Nothing is uploaded.
  2. What is stored is not your face. Mugam keeps a list of numbers, scrambled with a secret random rotation and encrypted with a key this browser won't let anyone export. Set up your face again and the old numbers become useless.
  3. A live person, not a photo. Each sign-in asks for two random movements, in an order nobody can predict.
  4. The server only sees a signature. Your face unlocks a private key on this device, which signs a one-time challenge. The server stores public keys only, so a stolen database signs nothing.
  5. Every sign-in is on the record. Your security log is a hash chain. Edit one line and the chain shows it.

Before we see your face.

What Mugam uses: your camera, only while the circle is on screen, to make a face template.

Where it goes: nowhere. The template is encrypted and stays on this device. The server receives only a public key.

Why: to sign you in. Nothing else, no ads, no sharing.

How to stop: in your account, choose "Remove face data from this device" or "Delete account". Either one erases it.
